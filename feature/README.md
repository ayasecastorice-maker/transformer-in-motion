# 字间 · Transformer

这部 4 分钟的中文动画从「小猫坐在垫子上」出发，算清一个位置怎样取回上下文，再沿着模型的计算路径，看到长序列注意力和逐词推理如何工作。全片 20 镜，2560 × 1440、60 fps，共 14,400 帧，带中文字幕与原创双声道音效，无旁白。

## 复算片中关键数字

**一个查询。** 对词块「坐在」，查询为 `[1, 0, 1, 0]`。它与「垫子」的键 `[1, 0, 2, 0]` 做点积得 3。四个点积 `[2, 1, 3, 0]` 除以 √4，逐行做 softmax 后得到约 `[0.2760, 0.1674, 0.4551, 0.1015]`。值向量的第一列为 `[1, 0, 1, 0]`，故输出第一维约为 **0.731**。

**两个方向。** 同一张权重矩阵里，查询「坐在」读取「垫子」约为 45.5%，反向约为 21.5%。每个查询都用自己的整行分数归一化。各方向的权重和片尾的词表概率均为人工算例。

**两个头。** 在多头算例中，两个头共享输入 X。第一头交换查询的第 1、2 维，第二头保留原查询，两者都取 K=X。两头分别选取 X 的前两列、后两列作为值，得到 `[0.731, 0.269]` 和 `[1.122, 0.189]`，再拼接并做输出投影。影片给出具体矩阵。原始基础模型使用 8 个头，每头的键和值为 64 维，输出宽度 512。[原始 Transformer 论文，第 3.2 节](https://arxiv.org/html/1706.03762v7#S3.SS2)

**两块数据。** 将同一个查询的缩放分数分为 `[1, 0.5]` 和 `[1.5, 0]`。第一块处理后，最大分数 m=1、指数和 ℓ≈1.60653、带权的第一维值之和 u=1。第二块令 m 升到 1.5，旧 ℓ 与 u 都需乘 exp(−0.5) 后再加上新块贡献。最终 ℓ≈2.19754，u≈1.60653，商仍为 0.731。影片以单行、单分量呈现实际分块计算的核心。FlashAttention 通过片上分块降低显存读写，稠密计算量仍随序列长度平方增长。[FlashAttention 论文](https://arxiv.org/abs/2205.14135)

## 新镜头的计算

**RoPE 的转盘。** 对一个二维分量对，取相同初始单位向量与每格 30° 的教学频率。查询、键位于第 1、3 格时相差 60°；一起移至第 2、4 格仍相差 60°，所以两次点积都是 0.5。一般形式为 `(Rₘq)ᵀ(Rₙk) = qᵀRₙ₋ₘk`，不同分量对使用不同频率。[RoFormer](https://arxiv.org/abs/2104.09864)

**线性注意力的两条路径。** 取正特征查询 [1, 2] 和三个正特征键 [1, 1]、[2, 1]、[1, 2]，值为 2、4、1。逐对核权重为 3、4、5，输出为 (6+16+5)/(3+4+5)=2.25。先累积也可得到 z=[4, 4]、S=[11, 8]，再算 (11+16)/(4+8)=2.25。这个等式针对所选特征核成立。用它替代 softmax 时，模型的注意力函数发生改变。[Transformers are RNNs](https://proceedings.mlr.press/v119/katharopoulos20a.html)

**预填与逐词推理。** 第一步并行处理四个前缀词，并在每个解码器层保留旧 K/V。第五和第六个位置各追加自己的 K/V，查询读到的前缀分别长 5 和 6。对精确的稠密因果注意力，固定头数与维度时，每一步的注意力读取仍随已见序列长度增长。[KV 缓存原理](https://huggingface.co/docs/transformers/en/cache_explanation)

**分组查询。** KV 缓存有效载荷字节数为 `2 × 批大小 × 层数 × 序列长度 × KV头数 × 头宽 × 每元素字节数`。对 1 条 4096 词元序列，取 32 层、头宽 128、FP16。8 个 KV 头需 512 MiB；保留 8 个查询头，以 2 组 KV 服务它们，缓存只需 128 MiB。这里计算的是 KV 张量自身的占用。[GQA 论文](https://arxiv.org/abs/2305.13245)

## 画面与工程

墨字、套印、网版和版画都在 Canvas 2D 中绘制。FlashAttention 与相邻镜头共用浅色纸底，当前数据块与读数以朱红高亮。前馈镜头从纵剖切到横截面，架构镜头用水平矩形与正交连线呈现各层的 K/V 投影。[视觉参考](https://x.com/Kimi_Moonshot/status/2081757327146045450)

`timeline.js` 定义片长、帧率、画幅、分镜及字幕。`attention.js`、`attention-lab.js`、`rope.js`、`flash.js`、`linear.js` 和 `inference.js` 绘制注意力相关运算，`architecture.js` 绘制结构图，`plates.js` 与 `atlas.js` 绘制其余镜头。`score.js` 合成音轨，`player.js` 将音画同步。重制命令见[导出工具说明](tools/README.md)。
